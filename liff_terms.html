第1条（適用）
  1. 本規約は、【会社名】（以下「当社」）が提供するSNS自動投稿サービス「AiPost」（以下「本サービス」）の利用に関する条件を定めるものです。
  2. 本サービスの画面に表示するご利用上の注意や料金の案内も、本規約の一部となります。
第2条（同意）
  1. 本サービスを初めて開いた時に表示する画面で、本規約とプライバシーポリシーに同意する操作をしてから、本サービスをご利用ください。
  2. プランをお申し込みいただく時は、プラン画面で、改めて本規約とプライバシーポリシーに同意する操作をしていただきます。
  3. 当社は、同意の操作をした日時を記録します。
  4. 本規約に同意いただけない場合は、本サービスをご利用いただけません。
第3条（サービスの内容）

本サービスは、LINEを通じて、次の機能を提供します。

  1. AIによる投稿文・ハッシュタグの作成。
  2. SNS（X・Instagram・Threads）への予約投稿と、予約の修正・キャンセル。
  3. 画像のSNSごとの切り抜き。
  4. 投稿の分析（LITEプラン以上）。
  5. 投稿履歴の表示と、本サービスから投稿した投稿の削除（X・Threads）（PERSONALプラン以上）。
  6. お知らせ・よくある質問・問い合わせ。
  7. その他、当社が定める機能。
第4条（お試し）
  1. LINEで本サービスの公式アカウントを友だち追加した方は、プランをお申し込みいただく前でも、次の機能をお試しとして無料でご利用いただけます。
    （1）投稿文とハッシュタグの作成。1日に当社が定める回数（現在は20回）までです。
    （2）店舗情報の登録。
    （3）お知らせ・よくある質問・問い合わせ。
  2. 予約投稿、SNSの連携、分析、画像の保存、投稿の削除、退会の手続きは、プラン（無料のFREEプランを含みます）をお申し込みいただくとご利用いただけます。
  3. お試しから、有料プランに自動で切り替わることはありません。
  4. 当社は、お試しでご利用いただける機能と回数を変えることがあります。変える時は、本サービスの画面でお知らせします。

第6条（ご利用期間）
  1. ご利用期間は、プランをお申し込みいただいた日から1か月ごとです。例えば、10月15日にお申し込みいただいた場合、最初のご利用期間は10月15日から11月14日までで、11月15日が次回更新日です。
  2. 翌月に、お申し込みいただいた日と同じ日がない時は、その月の末日が次回更新日です。例えば、1月31日にお申し込みいただいた場合、次回更新日は2月28日（うるう年は2月29日）です。
  3. ご利用期間は、退会のお申し込みがない限り、次回更新日に自動で更新します。
  4. ご利用期間と次回更新日は、プラン画面と設定画面でご確認いただけます。
第7条（試験運用・料金のお支払い）
  1. 本サービスは、現在、試験運用中です。試験運用の間は、有料プランを含め、料金は発生しません。
  2. 試験運用の間は、機能や画面を変えることや、本サービスを一時的にご利用いただけなくなることがあります。
  3. 料金のお支払いを始める時は、開始日とお支払いの方法を、開始日の30日前までに、本サービスの画面でお知らせします。
  4. 料金のお支払いを始めた後は、有料プランの料金を、ご利用期間ごとにその初日に、クレジットカードでお支払いいただきます。決済は決済代行事業者（Stripe）を通じて行い、当社はクレジットカードの番号を保持しません。
第8条（プランの変更）
  1. プランの変更は、プラン画面から行えます。
  2. FREEプランから有料プランへの変更は、お申し込みの時点で適用します。ご利用期間は、その日から1か月ごとになります。
  3. 有料プランどうしの変更と、有料プランからFREEプランへの変更は、次回更新日から適用します。それまでは、変更前のプランをそのままご利用いただけます。
  4. 前項の変更は、次回更新日の前日まで、プラン画面から取り消せます。
第9条（退会）
  1. プランをお申し込みいただいた方は、設定画面から退会をお申し込みいただけます。
  2. 退会をお申し込みいただいた後も、ご利用期間の終了日まで、引き続きご利用いただけます。退会は、次回更新日に効力が生じます。
  3. 退会のお申し込みは、ご利用期間の終了日まで、設定画面から取り消せます。
  4. 退会の効力が生じた時に、当社は次のことを行います。
    （1）次回更新日以降の予約を取り消します。
    （2）店舗情報・予約と投稿の記録・分析データ・画像・アクセストークン・問い合わせなど、当社が保管する利用者のデータを削除します。削除したデータは、元に戻せません。
  5. 退会しても、SNSに投稿済みの投稿は削除されません。必要な場合は、退会の効力が生じる前に、予約確認画面の「投稿削除」（X・Threads）、またはInstagramのアプリから削除してください。
  6. 退会した後も、プライバシーポリシーに定める情報は、定める期間保管します。
  7. 退会した後も、LINEの友だちのままであれば、お試しとしてご利用いただけます。
第10条（返金）
  1. お支払いいただいた料金は、ご利用期間の途中で退会した場合やプランを変更した場合も、返金しません。日割りでの返金も行いません。
  2. 前項にかかわらず、法令で返金が必要な場合と、当社の責任で本サービスをご利用いただけなかった場合は、当社が定める方法で返金します。

第12条（XへのURL付き投稿の禁止）

本サービスでは、XへのURL付き投稿に対応していません。

  1. 投稿文にURLが含まれる場合、Xは自動的に投稿先から除外されます。
  2. URLの直接記述以外にも、日本語・記号・短縮URL・QRコード誘導テキスト等によるURL表現（以下「迂回行為」）も同様に禁止します。
  3. 迂回行為が確認された場合は、本規約違反として利用停止・登録解除の対象となる場合があります。
⚠️ 迂回行為とはURLを直接記述せず、他の方法でリンク先を示す行為を指します。意図的な迂回行為が確認された場合はアカウントを停止する場合があります。不明な点は事前に運営までお問い合わせください。
第13条（AI投稿文作成機能）
  1. AIによる投稿文の作成は、プランをお申し込みいただくと、回数の制限なくご利用いただけます。お試しの間は、第4条に定める回数までです。
  2. AIが作成した投稿文の著作権は、利用者に帰属します。
  3. 当社は、AIが作成した投稿文の品質・正確性・適法性を保証しません。
  4. AIが作成した投稿文を投稿する前に、必ず内容をご確認ください。
  5. AIが作成した投稿文を利用したことによる損害について、当社は責任を負いません。
第14条（SNSアカウントの連携と安全管理）

本サービスでは、投稿や分析を行うために、各SNSが発行する「アクセストークン」をお預かりします。

アクセストークンとは？
利用者の許可にもとづいて各SNSが発行する、本サービス専用の「合鍵」のようなものです。SNSのパスワードとは別のもので、以下の性質があります。
・本サービスが使う権限は、投稿・投稿の反応（いいね等の数値・コメント）の取得・本サービスから投稿した投稿の削除に限ります。
・SNSのパスワードの確認や変更には使えません。
・利用者がいつでも無効にできます。
  1. 暗号化による安全管理
    お預かりするアクセストークンは、暗号化したうえで保管し、そのままでは読めない形にしています。読み出して使うのは、投稿・分析・削除の処理に限ります。
  2. 当社が預かるもの・預からないもの
    【預かるもの】アクセストークン（暗号化して保管）・SNSのユーザーIDとアカウント名。
    【預からないもの】SNSのパスワード・クレジットカードの番号。
    店舗情報など、そのほかの情報の取り扱いは、プライバシーポリシーをご確認ください。
  3. パスワードについて
    当社はSNSのパスワードを一切保持していません。パスワードを忘れた場合は各SNSのサポートにお問い合わせください。当社では対応できません。
  4. アクセストークンの取り消し
    設定画面の「SNS連携」タブから、いつでも連携を解除できます。各SNSの設定画面から、アクセストークンを無効にすることもできます。
  5. 免責
    当社は適切なセキュリティ管理を行いますが、各SNS側のシステム障害・仕様変更、または利用者自身のアカウント管理に起因する問題については対応できない場合があります。
第15条（利用者アップロード画像の取り扱い）
  1. 利用者は、本サービスにアップロードする画像について、自らが著作権・肖像権その他の権利を有すること、または当該権利者から適法な使用許諾を得ていることを保証するものとします。
  2. 前項の保証に反し、利用者がアップロードした画像が第三者の著作権・肖像権その他の権利を侵害していることが判明した場合、利用者は自己の責任と費用負担において解決するものとし、当社が損害を被った場合はこれを賠償するものとします。
  3. 当社は、権利者その他の第三者から権利侵害の申立てを受けた場合、利用者への事前通知を要せず、当該画像を含む投稿の停止・画像の削除を行うことができます。
  4. 当社は、アップロードされた画像について投稿前に個別の審査を行う義務を負いません。ただし、明らかに不適切と判断される画像については、投稿前であっても利用を停止する場合があります。
⚠️ 他人が撮影した写真、インターネット上で見つけた画像、著名なキャラクター・ロゴ等、ご自身が権利を持たない画像のアップロードはお控えください。権利侵害が疑われる画像は、運営にて予告なく利用を停止する場合があります。
第16条（匿名統計データの利用）

本サービスでは、PROプランの「同業種・同エリア平均との比較」機能のために、LITEプラン以上の利用者の分析データを匿名化した上で統計処理に使用します。個人や店舗を特定できる情報は一切含まれません。詳細はプライバシーポリシーをご確認ください。
